# تمشک شوتر (Berry Shooter)

بازی تیراندازی گروهی (موج دشمن) برای ویندوز، فقط با مکعب و کپسول یونیتی. **پروژهٔ مرجع SDK یونیتی تمشک** است و تقریباً همهٔ امکانات SDK را نشان می‌دهد.

**ویژگی‌ها**
- بازی تک‌نفره، ساخت اتاق، ورود به اتاق (تا ۸ نفر).
- ورود به بازی از سه راه: از اتاق لانچر، از داخل خود بازی (لیست روم‌ها، کد اتاق، ساخت اتاق) و با IP.
- پروتکل UDP، TCP یا خودکار (اول UDP، اگر کار نکرد TCP).
- دو لیست در لابی: افراد داخل اتاق بری و افراد واردشده به بازی؛ با کلیک روی هر نفر همهٔ جزئیاتش دیده می‌شود.
- تب‌های اطلاعات: لانچر، حساب، اتاق، شبکه، دوستان، آزمایش SDK.
- رابط **فارسی و انگلیسی** با تعویض زنده (تنظیمات > زبان).
- یونیتی ۲۰۲۱٫۳ به بالا و یونیتی ۶ (6000.0.50f1).

**شروع سریع**
1. یونیتی ۲۰۲۱٫۳ یا یونیتی ۶ را با Windows Build Support نصب کنید.
2. Unity Hub > Add > همین پوشه.
3. منوی **Berry Shooter > 2. Create the full main scene** و بعد Play.
4. اگر کلیدها کار نکرد: `Edit > Project Settings > Player > Active Input Handling = Both`.
5. ساخت exe: **Berry Shooter > 3. Build Windows**.

راهنمای کامل قدم‌به‌قدم: [docs/GUIDE.fa.md](docs/GUIDE.fa.md) — نسخهٔ انگلیسی: [README.md](README.md)
